# DXVK Game Manager

Windows-утилита для локальной установки DXVK в папку игры с резервными копиями,
проверкой файлов и откатом. Русский интерфейс. Проект [AnyKey.blog](https://anykey.blog).

**Экспериментальная версия 0.2.0.** Проверена на Windows 10 x64; совместимость
с другими системами и играми требует проверки. Python для готового EXE не нужен.

## Скачать

- [EXE 0.2.0](https://github.com/d0xt0p/dxvk-game-manager/releases/download/v0.2.0/DXVK-Game-Manager-0.2.exe) — готовое приложение для Windows x64.
- [Релиз 0.2.0 и архив с исходниками](https://github.com/d0xt0p/dxvk-game-manager/releases/tag/v0.2.0).
- [Все версии](https://github.com/d0xt0p/dxvk-game-manager/releases). Для новых пользователей рекомендуется ветка 0.2.

Сверьте скачанный файл с SHA256SUMS.txt из релиза. Сборки не имеют цифровой подписи.
DLL DXVK скачиваются отдельно с [официальной страницы](https://github.com/doitsujin/dxvk/releases).

## Возможности

- Определение архитектуры EXE по PE-заголовку: x86 или x64.
- Наборы DLL для D3D8, D3D9, D3D10 и D3D11; проверка архитектуры DLL.
- Установка из локальной папки, tar.gz или zip без распаковки произвольных путей.
- Создание dxvk.conf с выбором GPU и HUD для проверки в игре.
- Сохранение исходных файлов, SHA-256 и журнала до замены файлов игры.
- Откат, защита изменённых файлов от перезаписи и восстановление после прерванных операций.
- Просмотр логов выбранного EXE и выбор другой рабочей папки логов.

Выбирайте GPU из списка: программа запишет точное Vulkan-имя автоматически. Помощник API анализирует EXE и связанные DLL движка и предлагает вероятный вариант с ручным подтверждением.

## Как пользоваться

1. Закройте игру. Выберите настоящий EXE игры, а не установщик или лаунчер.
2. Проверьте EXE и статус. Выберите API игры; подсказка по импортам может ошибаться.
3. Выберите локальный пакет DXVK и нужную видеокарту/фильтр.
4. Проверьте ограничения античита, затем подготовьте установку и прочитайте план замены файлов.
5. Запустите игру обычным способом. Подтвердите GPU по HUD и свежим логам.
6. Для восстановления закройте игру и нажмите «Удалить DXVK / откат».

Подробности и разбор проблем: [USAGE.md](USAGE.md).

Если DXVK или моды уже стояли вручную, они будут сохранены как исходные файлы.
Откат вернёт именно этот набор, а не обязательно чистую игру. Неизвестные ручные
установки без журнала приложение автоматически не удаляет.

## Что важно перед установкой

**DX12 не поддерживается.** DXVK переводит Direct3D 8/9/10/11 в Vulkan.
Он не переводит OpenGL и не нужен для нативного Vulkan-режима игры.

**Античит и мультиплеер:** подмена DLL может привести к отказу запуска или санкциям
для аккаунта, в том числе в играх со встроенной сетевой частью.

**Windows официально не поддерживается разработчиками DXVK.** Возможны проблемы
с загрузкой DLL, оверлеями, полноэкранным режимом, HDR/VRR и несколькими мониторами.
DXVK 3.x требует совместимый Vulkan 1.4 и дополнительные возможности устройства;
номер версии Vulkan сам по себе не доказывает совместимость.

Программа не устанавливает драйверы и не меняет реестр. Не заменяйте DLL в Windows,
System32 или SysWOW64. Для операций нужны права записи в папку игры.

## Кейс Watch Dogs

На конфигурации Intel HD 4000 и NVIDIA RTX A2000 Laptop GPU удалось получить
рендеринг первой Watch Dogs через DXVK 3.1.1 на A2000. Существующие журналы
показывали чтение dxvk.conf и создание устройства NVIDIA.

Это отдельный успешный случай, а не гарантия совместимости. FPS загрузочного
экрана не используется как игровой бенчмарк.

## Разработка и проверки

Python 3.11+ с Tkinter. Для запуска сторонние пакеты не нужны:

```powershell
python app.py
python -m unittest -v test_core test_discovery
```

На Windows 10 x64 пройдено 27 автоматических тестов. Сводка: [TEST-REPORT.txt](TEST-REPORT.txt).
Сборка автономного EXE: `Build.cmd` (создаёт .venv и устанавливает PyInstaller 6.22.3).
Бинарные релизы являются исходными сборками; полная побайтовая воспроизводимость сборки не заявляется.
