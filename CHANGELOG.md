# История изменений

## 0.2.0 — 23 ноября 2026

- Выбор видеокарты из списка Vulkan-устройств вместо обязательного ручного ввода.
- Точное Vulkan-имя GPU автоматически становится фильтром DXVK.
- Показ типа GPU и версии Vulkan, автовыбор, обновление списка и ручной режим.
- Отдельный процесс проверки драйвера с тайм-аутом; Vulkan SDK не нужен.
- Анализ импортов EXE и связанных DLL движка; приоритет ближайших зависимостей.
- Подсказка API с явным применением пользователем и объяснением ограничений.
- Отказ от неоднозначного фильтра для GPU с совпадающими именами.
- 27 автоматических тестов; проверка готового EXE на Windows 10 x64.

## 0.1.0 — 23 ноября 2026

- Русский интерфейс выбора EXE и локального пакета DXVK.
- Определение PE-разрядности x86/x64 и подсказки по импортам EXE.
- Ручной выбор D3D8/9/10/11 и фильтра GPU.
- Проверка разрядности DLL из папки, tar.gz или zip.
- Резервные копии, журнал до изменения файлов, проверка SHA-256 и откат.
- Защита изменённых файлов от перезаписи при откате и повторение прерванного восстановления.
- Просмотр логов, предупреждения о DX12, Windows и античите.
- 16 автоматических тестов и проверка установки/отката на изолированных копиях реальных файлов.

Обе версии экспериментальные. Поддержка API не гарантирует совместимость конкретной игры.
