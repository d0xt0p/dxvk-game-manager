# DXVK Game Manager 0.2

Локальная Windows-утилита с русским интерфейсом. Выбирает архитектуру DLL по PE-заголовку EXE, показывает признаки API по обычным и отложенным импортам, устанавливает выбранный набор DXVK и восстанавливает исходные файлы.

## Запуск

Готовый `DXVK-Game-Manager-0.2.exe` находится в папке `releases` проекта. Python для него не нужен. Это пробная неподписанная сборка для Windows x64; проверена на Windows 10. Поддержка Windows 11 пока требует отдельной проверки.

Из исходников: Python 3.11+ с Tkinter, двойной щелчок по `Start.cmd`. Внешних библиотек для работы приложения нет. `Build.cmd` создаёт отдельное окружение и собирает EXE через PyInstaller 6.22.3. Для сборки требуется интернет.

## Пробный запуск

1. Закройте игру. Выберите настоящий EXE. Для Watch Dogs: `C:\Games\Watch Dogs\bin\watch_dogs.exe`.
2. Нажмите «Проверить EXE и статус». Архитектура определяется по PE Machine; ARM/ARM64 отклоняются. Программа читает обычные и отложенные импорты EXE, затем импортируемые локальные DLL движка (не более 24 файлов, глубина до 2, суммарно до 256 МБ). Ничего из игры не загружается как исполняемый код. Ближайшие к EXE импорты имеют приоритет над косвенными; один поддерживаемый API на ближайшем уровне даёт кнопку «Подсказка: D3D11» или другой вариант. Нажатие заполняет выбор API. Это предположение, а не обнаружение активного рендерера. В Watch Dogs обнаружены D3D11 в движке `disrupt_b64.dll` и OpenGL во вспомогательной TXAA-библиотеке; подсказка предлагает D3D11. При неоднозначности выбор остаётся ручным; кнопка «Как выбрать API?» объясняет порядок действий.
3. Скачайте пакет с [официальной страницы DXVK](https://github.com/doitsujin/dxvk/releases). Выберите `.tar.gz`, `.zip` или распакованную папку с `x32`/`x64`. Подлинность DLL утилита не проверяет; проверяет формат PE и архитектуру. DLL не включены в поставку приложения.
4. Для первой Watch Dogs выберите D3D11. В поле «Видеокарта» выберите нужное устройство из списка: приложение само получит его точное Vulkan-имя и запишет фильтр в конфигурацию. Тип карты и версия Vulkan рядом с названием не попадут в фильтр. На проверенной машине найдено `NVIDIA RTX A2000 Laptop GPU`, Vulkan 1.4.341. Список содержит устройства установленного Vulkan-драйвера; GPU без такой поддержки в него не попадут. Доступны «Автовыбор игрой (без фильтра)», «Обновить GPU» и ручной ввод. Изначально выбран автовыбор, чужая модель GPU не подставляется. Одинаковые или пересекающиеся имена, которые нельзя различить фильтром, отклоняются. Оставьте HUD для проверки фактического GPU в игре.
5. Подтвердите проверку ограничений античита и подготовьте установку. Окно покажет точную папку и список добавляемых/заменяемых файлов. Уже существующие DLL могут принадлежать модам или предыдущей DXVK.
6. После установки запустите игру обычным способом. Проверьте GPU в HUD. «Проверить логи» читает журналы выбранного EXE рядом с ним; другая кнопка позволяет выбрать рабочую папку или каталог `DXVK_LOG_PATH`. Отсутствие логов не доказывает отсутствие DXVK. Старые логи и перечисление адаптеров не подтверждают текущий выбор GPU.
7. Закройте игру и выполните «Удалить DXVK / откат». Будут удалены только добавленные этой установкой файлы и восстановлены исходные байты заменённых файлов. Если DXVK стоял вручную до этого, исходным набором будет именно он: откат приложения не превращает такую папку в чистую установку игры.

## Резервные копии и восстановление

Рядом с EXE создаётся `.dxvk-game-manager`. Не удаляйте и не редактируйте эту папку до отката. `active.json` содержит журнал; подпапки со случайными идентификаторами содержат оригиналы и первоначальный план. SHA-256 проверяет целостность копий, но не подтверждает доверие к источнику DLL.

Все копии и план восстановления записываются до замены файлов игры. Каждый файл заменяется атомарно, однако операция над несколькими файлами не является единой транзакцией файловой системы. После сбоя статус предлагает откат; его можно повторить, если восстановление тоже прервалось. Одновременные операции двух экземпляров блокируются.

Перед откатом проверяются все копии и все целевые файлы. Если файл изменили после установки, откат останавливается. Сохраните изменённый файл отдельно и уберите его из игровой папки, затем повторите откат. Принудительной перезаписи нет. Резервные копии сохраняются после успешного восстановления. Права, временные метки и альтернативные потоки NTFS не восстанавливаются — резервируется содержимое обычных файлов.

Ручные установки без журнала утилита автоматически не удаляет. Повторная установка или обновление через утилиту требуют предварительного отката. Журнал общий для папки EXE: в одной папке нельзя вести несколько независимых наборов DXVK. Ссылки и junction не поддерживаются. Требуются права записи в папку игры; автоматического повышения прав нет. Игра должна быть закрыта, в том числе перед восстановлением.

## Ограничения DXVK

- Поддержка API не гарантирует совместимость игры. DXVK переводит D3D8/9/10/11 в Vulkan; DX12 и OpenGL не поддерживаются. Для нативной Vulkan-игры эта подмена не нужна.
- Для D3D8 нужны `d3d8.dll` и `d3d9.dll`; для D3D9 — `d3d9.dll`; для D3D10 — `d3d10core.dll`, `d3d11.dll`, `dxgi.dll`; для D3D11 — `d3d11.dll`, `dxgi.dll`.
- Поиск GPU использует системную `vulkan-1.dll`, не требует Vulkan SDK и выполняется отдельно от интерфейса с ожиданием до 15 секунд. Для программы x64 проверяется x64 Vulkan-драйвер: наличие нужного x32-драйвера для 32-битной игры этим не проверяется. Версия Vulkan — только часть требований DXVK; дополнительные возможности устройства здесь не проверяются.
- DXVK 3.x требует совместимый Vulkan 1.4 и определённые возможности устройства. Для 2.7 и новее в ветке 2.x документация указывает Vulkan 1.3 с дополнительными требованиями; проверяйте требования конкретного релиза. Таблицу минимальных Linux-драйверов нельзя использовать как таблицу Windows-драйверов.
- DXVK официально не поддерживает Windows. Возможны проблемы загрузки DLL, полноэкранного режима, HDR, VRR, оверлеев и нескольких мониторов. `dxvk.conf` обычно читается из рабочей папки, которая может отличаться от папки EXE; проверяйте `Found config file` и `Effective configuration` в логе.
- Античит и встроенный мультиплеер могут расценить подмену DLL как нарушение. Даже запуск одиночного режима не гарантирует безопасность аккаунта.
- Не копируйте DXVK в Windows, System32 или SysWOW64. Утилита блокирует установку в каталог Windows и не изменяет реестр или драйверы.

## Проверки

`python -m unittest -v test_core test_discovery` запускает 27 тестов. Проверяются PE32/PE32+, импорты и delay imports, все наборы DLL, побайтовое восстановление, конфликты, повреждение копий, прерванные операции, архивы, блокировка второго экземпляра, отклонение DX12, небезопасные пути, старые логи, зависимости движка, неоднозначность API, точность фильтра GPU, совпадающие имена, очистка Vulkan instance при ошибке, сбой и тайм-аут проверки драйвера.

Тестовые PE-файлы не являются играми и не запускаются. Это проверка управления файлами, а не совместимости игрового рендеринга. Совместимость на вашей системе оценивается запуском конкретной игры с проверкой HUD и свежих логов.
