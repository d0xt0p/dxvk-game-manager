# Участие в разработке

Ошибки и предложения принимаются через Issues; изменения кода — через Pull Requests.
Для ошибки укажите версию утилиты, Windows, DXVK и драйвера, модель GPU,
разрядность игры, выбранный API и точный текст сообщения.

Перед публикацией логов удалите имена пользователей, личные пути, токены и другие
приватные данные. Не прикладывайте EXE игр, игровые ресурсы и резервные копии DLL.

Для локального запуска нужен Python 3.11+ с Tkinter. Зависимостей для запуска нет:

```powershell
python app.py
python -m unittest -v test_core test_discovery
```

В теге v0.1.0 запускайте только `python -m unittest -v test_core`.
Тесты файловых операций используют отдельные папки рядом с исходниками.
Проверка совместимости с реальной игрой — отдельный ручной этап.

Изменения установки и отката должны сохранять оригиналы до записи, проверять
конфликты и позволять восстановление после прерывания. Не добавляйте подмену
системных DLL, обход античита, автоматический запуск от администратора или
обещания достоверного определения API по статическому анализу.
