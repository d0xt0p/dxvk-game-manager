# Безопасность

Проект находится на ранней стадии. Исправления планируются для актуальной ветки;
исторические релизы 0.1.0 и 0.2.0 опубликованы для воспроизводимости.

Не публикуйте в Issues секреты, полные приватные журналы и рабочие резервные копии.
Если на странице Security доступно «Report a vulnerability», используйте приватное
сообщение. Иначе откройте Issue с просьбой согласовать закрытый канал без раскрытия
деталей уязвимости. Гарантированный срок реакции не установлен.

Устанавливайте DXVK только из доверенного официального источника. PE-проверка и
SHA-256 не подтверждают безопасность DLL. Перед операциями закрывайте игру.
Не удаляйте .dxvk-game-manager до восстановления исходных файлов.
